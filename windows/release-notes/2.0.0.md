### 主な変更
- Windows 版を C#（WPF）のネイティブアプリとして書き直しました。macOS 版（v2.0.2）と同じ機能を使えます
  - 共有用ウィンドウ（Zoom などでアプリのウィンドウだけを共有するときに、コメントを重ねたウィンドウを共有する）
  - 授業ログをこの PC（ドキュメント\Commentable\logs）にも保存
  - 配信者の鍵の保存場所を Dropbox や OneDrive のフォルダに変更（別の Mac / PC と同じ部屋で配信できます）
  - アンケート、ダッシュボード、授業参画度、カメラ映像の表示
- 自動アップデートに対応しました。新しいバージョンがあると裏でダウンロードし、「再起動」を押すだけで更新できます（「あとで」を選んだときは終了時に更新します）
- Electron 版（v1.6.3 まで）からは自動では入れ替わりません。このバージョンを手動でインストールしてください
- 人物切り抜きは Windows 版では使えません（Electron 版の Windows と同じ）
